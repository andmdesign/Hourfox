# Hourfox

Минималистичный трекер времени для macOS. Живёт в Notch MacBook, а на Mac без выреза в строке меню.

Работает офлайн, без аккаунта и аналитики. **[Сайт](https://andmdesign.github.io/Hourfox/) · [Скачать](https://andmdesign.github.io/Hourfox/) · [English](README.md)**

## Возможности

- **Таймер в Notch.** Наведите курсор, напишите, чем заняты, и запустите. Секундомер или обратный отсчёт, есть пауза.
- **Проекты:** цвета, ставка в час или цена за проект, расходы и реальные деньги в час.
- **Задачи:** список, канбан, доски по приоритету, проектам и срокам.
- **Журнал:** список или календарь дня. Записи можно двигать, растягивать, делить и склеивать, ошибки отменять.
- **Отчёты** за день, неделю, месяц и год: карта года, часы работы и карточка итогов.
- **Экспорт** в PDF и CSV: шаблоны, округление, отчёты по расписанию.
- **Заметки**, закреплённые задачи, умный ввод (`созвон @клиент 30м`), синхронизация с Календарём.
- **Под себя.** У каждой необязательной функции есть выключатель, по умолчанию она выключена. 8 языков интерфейса.

## Установка

1. Скачайте [Hourfox-Apple.zip или Hourfox-Intel.zip](https://andmdesign.github.io/Hourfox/), распакуйте и перенесите Hourfox в «Программы».
2. Приложение пока не нотаризовано, поэтому первый запуск macOS заблокирует. Откройте его, затем разрешите в **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. Или проверьте код и соберите сами.

Нужна macOS 14 или новее. Работает на Apple Silicon и Intel.

## Сборка

Достаточно Command Line Tools (`xcode-select --install`), Xcode не нужен.

```bash
./build.sh            # build/Hourfox.app
./build.sh --install  # собрать, положить в /Applications и запустить
```

## Данные

Всё лежит в `~/Library/Application Support/Hourfox/`: `data.json`, ежедневная копия в `backups/` (30 дней) и копия прошлого запуска.

Приложение не ходит в сеть, с одним исключением. Google Календарь скрыт, пока вы не добавите свой OAuth-клиент: скопируйте `Resources/GoogleOAuth.example.plist` в `Resources/GoogleOAuth.plist` и заполните. Файл в git не попадает. В готовых сборках ключей нет.

Подробности о проекте и проверках в [английском README](README.md).
